Custom Media IDs
Override default randomized library items with a custom list. If list is empty, library content is used.
If enabled, limits (e.g. Max Items) will also apply to custom lists. By default, custom lists are unlimited.
Select a custom playlist from below to copy its IDs into the input field below.
Enter the IDs of the items you want to show in the slideshow as your default content. You can separate them by new lines or commas.

Tip: You can simply paste full Jellyfin item URLs here and the IDs will be automatically extracted!

Genre & Tag Filters: You can filter items by genre or tag using prefixes:
  • genre:Action — Show items with the "Action" genre.
  • tag:2000s — Show items with the "2000s" tag.
You can list multiple tags/genres separated by a comma or newline. Multiple genres/tags are combined with OR (union) within their type. If you use both genres and tags, they are combined with AND. You can freely mix genre/tag filters with regular IDs, collection names, and playlist names.

Manual Trailer/Video Override: Specify a YouTube URL or a Jellyfin Item ID (e.g. Theme/Backdrop Video) in brackets:
e.g. ID DESCRIPTION [https://youtu.be/...] or ID [JellyfinItemId] DESCRIPTION
  • YouTube URL: Play a remote trailer from YouTube.
  • Jellyfin Item ID: Play the video of another library item (e.g. a Theme/Backdrop Video) using the native player.
You can add a description after the ID using any separator like space, pipe (|) or dash (-):
e.g. ID DESCRIPTION or ID | DESCRIPTION.
Note: If using a Collection/Playlist Name (instead of an ID) combined with a description, you MUST use the pipe (|) separator. The separator MUST NOT be a hex character (0-9, a-f).

Finding IDs: Look at the URL of the item page in your browser.
Example: https://your-jellyfin-url/web/#/details?id=your-item-id&serverId=your-server-id

Collections & Playlists: Enter the name of a collection or playlist to fetch all items inside it (uses first matching hit).
Note: There is currently no feedback if the name resolution succeeded; verify on the home page if the correct items are shown.
